# Faculdade

Trabalhos, exercícios e projetos das disciplinas da graduação (Ciência da Computação, UFFS).

## Disciplinas

- **C** — estruturas de dados, ordenação, hashing, tries
- **Java** — orientação a objetos
- **LFA** — Linguagens Formais e Autômatos
- **Grafos** — algoritmos em grafos e dígrafos
- **VHDL** — circuitos digitais (batalha naval, elevador)
- **Circuitos** — contador Gray, elevador
- **Prog Comp** — programação competitiva (problemas CSES)
- **SO** — Sistemas Operacionais
- **BD II / BD III** — Banco de Dados
- **Calc Num** — Cálculo Numérico (raízes, integração)
- **PLN** — Processamento de Linguagem Natural (Transformer)
- **Compiladores** — autômato, análise
- **CG** — Computação Gráfica (jogo FPS em Three.js no CG-TF)
